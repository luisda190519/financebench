# Abstract

Large language models are increasingly used by entrepreneurs and small businesses for financial analysis tasks—computing net present value, projecting cash flows, and assessing business viability—yet no standardized benchmark exists to measure their accuracy on structured numerical financial computations with exact ground truth. We introduce **FinanceBench**, a benchmark of 1,000 deterministic test cases spanning 10 financial analysis task categories, from revenue projection through NPV and IRR computation. Each case is paired with ground-truth values produced by a verified computational oracle implementing 15+ financial metrics per scenario using standard formulas for discounted cash flows, loan amortization, straight-line depreciation, and tax computation with loss carryforward. The dataset covers 10 business types representative of Latin American SMEs, three difficulty levels, and four economic scenarios, generated deterministically via seeded pseudo-random number generation for full reproducibility. We evaluate 10 state-of-the-art LLMs—both proprietary (GPT-4o, Claude 3.5 Sonnet, Gemini) and open-source (LLaMA 3, Mistral, DeepSeek, Qwen)—under standardized zero-shot conditions, comparing outputs against oracle values across up to 316 fields per case with three-tier tolerance thresholds (≤1%, 1–5%, >5%). **[PLACEHOLDER — KEY RESULTS]** [Best model] achieves [X]% overall field-level accuracy, with performance degrading along the computation chain from direct arithmetic ([Y]%) to cascading summary metrics ([Z]%). IRR computation and tax loss carryforward emerge as universal failure modes across all models. FinanceBench provides the first reproducible evaluation framework for structured financial analysis with exact numerical ground truth, enabling evidence-based model selection and identifying critical gaps in LLM numerical reasoning for financial applications. Dataset, oracle, and evaluation code are publicly available.
